# LUMÉ Design System

## Brand
**LUMÉ**  
Hair • Beauty • Experience

## Visual direction
Quiet luxury + contemporary editorial beauty studio.

Think: refined magazine layout, tactile photography, generous whitespace, sophisticated typography and restrained motion.

## Palette
- Ink: `#171614`
- Warm Ivory: `#F5F1EA`
- Soft Stone: `#D9D1C5`
- Muted Taupe: `#A69B8C`
- Deep Brown: `#302820`
- Accent Gold: `#B59A6A`

Use the gold sparingly. Do not turn the site into a gold-gradient luxury template.

## Typography
- Display: Cormorant Garamond or similar high-contrast editorial serif.
- Body/UI: Inter, Manrope or similar clean sans-serif.
- Large display headings should have tight but elegant line-height.
- Avoid excessive uppercase text.

## Layout
- Max content width: approximately 1280–1400px.
- Desktop: generous side margins.
- Mobile: 20–24px side padding.
- Use asymmetrical editorial compositions where appropriate.
- Avoid a page made entirely from equal-sized cards.

## Buttons
Primary: dark ink background, ivory text.  
Secondary: transparent/outlined with subtle hover fill.

Buttons should have a refined 200–350ms transition and a small directional movement on hover.

## Image treatment
- Prefer large photographic crops.
- Use natural skin/hair tones.
- Avoid excessive overlays.
- Use subtle grain only if performance permits.
- Temporary images should come from a centralized asset configuration so they can be replaced easily.

## UI rules
- Rounded corners should be subtle: mostly 0–12px depending on component.
- Do not use giant pill containers everywhere.
- No floating glassmorphism dashboard.
- No fake analytics widgets.
- No generic AI icon grids.
